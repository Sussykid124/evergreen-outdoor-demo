# Evergreen Outdoor Co. — Demo Website

A fictional portfolio website for a Fresno-area landscaping company.

## What's included
- 5 responsive pages
- Shared CSS and JavaScript
- Mobile navigation
- Demo lead form interaction
- Basic meta descriptions
- Clear conversion-focused calls to action
- No paid libraries or frameworks
- No invented reviews, awards, licenses, or customer claims

## Files
- `index.html` — Home
- `services.html` — Services
- `projects.html` — Project gallery
- `about.html` — About
- `contact.html` — Contact / estimate form
- `assets/styles.css`
- `assets/script.js`

## Preview locally
Open `index.html` directly in a browser.

## Deploy
This is a static site, so it can be deployed to Cloudflare Pages, Netlify, Vercel, or another static host.

For a real client:
1. Replace demo name/contact details.
2. Replace stylized gallery blocks with client-owned photos.
3. Connect the contact form to a real form endpoint or serverless function.
4. Add verified business facts, service area, reviews and licenses only when supplied/verified.
5. Connect the client's domain.
6. Add analytics and Search Console.

## Important
Evergreen Outdoor Co. is fictional. The site is a demo concept and should not be represented as a real customer project.
